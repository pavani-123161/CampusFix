# 🏫 CampusFix

### Building a Better Campus Together

CampusFix is a campus issue management system that helps students report problems around their campus and track their resolution status.

The platform provides separate Student and Admin roles, making it easier to report, monitor, and manage campus issues through a simple and user-friendly interface.

---

## 🎯 Problem Statement

Students regularly encounter problems around campus such as:

- Water leakage
- Electrical issues
- Broken infrastructure
- Internet problems
- Cleanliness issues
- Other campus-related problems

When these issues are reported through informal channels, it can be difficult to track whether they have been noticed, addressed, or resolved.

There is a need for a simple centralized platform where students can report campus problems and administrators can monitor and manage them efficiently.

---

## 💡 Solution

CampusFix provides a centralized campus issue management platform connecting students and administrators.

Students can report problems by providing:

- Issue title
- Category
- Location
- Priority
- Description

Administrators can then view reported issues, update their progress, and monitor overall campus issue statistics.

The dashboard also provides insights such as:

- Total reported issues
- Pending issues
- Issues in progress
- Resolved issues
- Campus resolution rate
- Issue categories requiring attention
- Recent campus activity

This creates a simple workflow from **reporting an issue to tracking its resolution**.
